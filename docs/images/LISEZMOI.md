# Image de fond

Dépose ici une image nommée **`background.jpg`** : elle sera utilisée automatiquement comme fond du site.

- Sans ce fichier, le site garde son dégradé pastel par défaut.
- Un voile clair est ajouté par-dessus l'image pour que le texte reste lisible. Son intensité se règle avec `--bg-veil` dans `docs/style.css`.
- Pour utiliser un autre nom ou format (`.png`, `.webp`…), modifie la ligne `--bg-image` en haut de `docs/style.css`.

Depuis GitHub, sans Git : ouvre ce dossier, puis **Add file → Upload files**, glisse l'image et clique sur **Commit changes**.

Conseils : une image d'au moins 1920 × 1080 pixels, aux couleurs claires, de moins de 500 Ko pour un chargement rapide.
